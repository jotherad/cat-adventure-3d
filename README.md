# Cat Adventure 3D 🐾🏰

A beautiful, browser-based 3D exploration game built with **Three.js**. Play as a grey cat, explore a medieval castle, find magical orbs, and befriended an orange companion!

## 🎮 Features
- **Exploration**: A vast forest with giant trees and a detailed medieval castle.
- **Physics & Collision**: Solid walls, stairs, and walkways to climb and explore.
- **Magic Orbs**:
  - **Cyan Orb**: Grants 3x movement speed.
  - **Pink Orb**: Unlocks a heartwarming cutscene and **Legendary Speed**.
- **Interactive Events**:
  - Summon a cozy house from the keep.
  - Eat cat food to grow into a **Giant Cat**.
  - Befriend an **AI Orange Cat** that follows you.
- **Cross-Platform**: Full support for Keyboard (WASD/Space/R) and **Mobile Touch Controls** (Virtual Joystick + Action Buttons).

## 🚀 How to Play
1. Open `index.html` in any modern web browser.
2. Use **WASD** to move and **Space** to jump.
3. Use **R** to reset your position if needed.
4. On mobile, use the on-screen joystick and buttons.

## 🛠️ Technology
- [Three.js](https://threejs.org/) - 3D Graphics Engine
- Vanilla JavaScript & CSS
- Web Audio API for synthesized sound effects

## 📦 Deployment
This project is ready to be hosted on **GitHub Pages** or converted to an APK using tools like **Capacitor** or **Website 2 APK Builder**.
